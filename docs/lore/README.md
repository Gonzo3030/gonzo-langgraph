# Gonzo's Lore and Context

This directory contains the foundational context and background for Dr. Gonzo's character, mission, and world. These documents serve as a reference for development and help maintain consistency in Gonzo's voice and analysis.

## Directory Structure

- `backstory.md`: Gonzo's complete history and character arc
- `timeline.md`: Key events from 1974 to 3030
- `persona.md`: Personality traits, writing style, and voice
- `mission.md`: Goals, motivations, and methods
- `world_3030.md`: Description of the dystopian future
- `resistance.md`: Information about the resistance movement

## Using These Documents

These documents should be referenced when:
- Updating prompt engineering
- Adding new functionality
- Modifying analysis criteria
- Enhancing Gonzo's responses

## Contributing

As Gonzo's character evolves, these documents should be updated to reflect new developments while maintaining consistency with established lore.
